Tema de la sesión

Inyección de dependencias (Depends)

1. Objetivo de la sesión

Al finalizar esta sesión, el aprendiz será capaz de extraer lógica repetida de los endpoints hacia dependencias reutilizables con Depends, construir dependencias parametrizables mediante clases, anidar unas dependencias dentro de otras y aplicarlas a un router completo.

2. Qué es una dependencia y por qué no es solo una función auxiliar

Los parámetros limite y desplazamiento se repiten en cada listado; la validación de que un socio existe se repite en cada endpoint que lo recibe. Una dependencia es una función —o una clase invocable— que FastAPI ejecuta antes del endpoint y cuyo resultado se inyecta como argumento.

Característica

Qué aporta

Se declara en la firma

Depends() va como valor del parámetro. El endpoint recibe el resultado ya listo, sin llamarla explícitamente.

Participa en la validación

Los parámetros de la dependencia se validan igual que los del endpoint y aparecen en /docs. Una función auxiliar normal no hace nada de eso.

Se anida

Una dependencia puede depender de otra. FastAPI resuelve el grafo completo antes de ejecutar el endpoint.

Se cachea por petición

Si dos dependencias piden la misma subdependencia, se ejecuta una sola vez en esa petición.

Puede interrumpir

Si lanza una excepción, el endpoint no llega a ejecutarse. Es la base de la autenticación.

Se sustituye en pruebas

dependency_overrides permite reemplazarla en los tests sin tocar el código de producción.

Idea clave

Una dependencia no es solo código compartido: es un punto de sustitución. Ese detalle, que hoy parece menor, es lo que el 14 de septiembre permitirá cambiar la base de datos real por una de prueba en los tests sin modificar una sola línea de los endpoints.

La diferencia es el mecanismo: DRF resolvía la reutilización con herencia de clases; FastAPI la resuelve con composición de funciones. Es más explícito —se ve en la firma qué necesita cada endpoint— y evita las jerarquías profundas de vistas que dificultaban seguir el flujo en DRF.

from typing import Annotated

from fastapi import Depends, Header, Query

from app.crud import libros as crud_libros

from app.datos import buscar_socio_por_id

from app.errores import ErrorDeDominio, RecursoNoEncontrado

class Paginacion:

 """Parámetros de paginación comunes a todos los listados."""

 def __init__(

 self,

 limite: Annotated[

 int, Query(ge=1, le=50, description="Máximo de elementos a devolver.")

 ] = 10,

 desplazamiento: Annotated[

 int, Query(ge=0, description="Elementos a omitir desde el inicio.")

 ] = 0,

 ):

 self.limite = limite

 self.desplazamiento = desplazamiento

 def aplicar(self, elementos: list) -> list:

 inicio = self.desplazamiento

 return elementos[inicio : inicio + self.limite]

class FiltroDeCatalogo:

 """Filtros del catálogo, parametrizable según el uso."""

 def __init__(self, permitir_agotados: bool = True):

 self.permitir_agotados = permitir_agotados

 def __call__(

 self,

 categoria: Annotated[str | None, Query()] = None,

 anio_min: Annotated[int | None, Query(ge=1450, le=2100)] = None,

 buscar: Annotated[str | None, Query(min_length=3, max_length=80)] = None,

 ) -> list[dict]:

 resultado = crud_libros.listar()

 if categoria is not None:

 resultado = [l for l in resultado if l["categoria"] == categoria]

 if anio_min is not None:

 resultado = [l for l in resultado if l["anio_publicacion"] >= anio_min]

 if buscar is not None:

 aguja = buscar.lower()

 resultado = [l for l in resultado if aguja in l["titulo"].lower()]

 if not self.permitir_agotados:

 resultado = [l for l in resultado if l["ejemplares_disponibles"] > 0]

 return resultado

def obtener_libro_existente(libro_id: int) -> dict:

 """Resuelve el libro de la ruta o corta la petición con 404."""

 return crud_libros.obtener_o_fallar(libro_id)

def socio_actual(

 x_socio_id: Annotated[int | None, Header(alias="X-Socio-Id")] = None,

) -> dict:

 """Identificación provisional por cabecera. El 1 de septiembre la sustituye JWT."""

 if x_socio_id is None:

 raise ErrorDeDominio("Debe indicarse la cabecera X-Socio-Id.")

 socio = buscar_socio_por_id(x_socio_id)

 if socio is None:

 raise RecursoNoEncontrado("un socio", x_socio_id)

 return socio

def exigir_bibliotecario(

 socio: Annotated[dict, Depends(socio_actual)],

) -> dict:

 """Dependencia anidada: se apoya en socio_actual y añade la comprobación de rol."""

 if socio["rol"] != "bibliotecario":

 raise ErrorDeDominio("Esta operación requiere el rol de bibliotecario.")

 return socio

# Alias para escribir firmas más cortas en los endpoints

PaginacionDep = Annotated[Paginacion, Depends()]

LibroExistente = Annotated[dict, Depends(obtener_libro_existente)]

SocioActual = Annotated[dict, Depends(socio_actual)]

Bibliotecario = Annotated[dict, Depends(exigir_bibliotecario)]

app/routers/libros.py — endpoints reescritos con dependencias

from typing import Annotated

from fastapi import APIRouter, Depends, Response, status

from app.crud import libros as crud_libros

from app.dependencias import (

 Bibliotecario,

 FiltroDeCatalogo,

 LibroExistente,

 PaginacionDep,

)

from app.errores import ConflictoDeNegocio

from app.schemas.error import DetalleDeError

from app.schemas.libro import LibroActualizar, LibroCrear, LibroRespuesta

router = APIRouter(

 prefix="/libros",

 tags=["Libros"],

 responses={404: {"model": DetalleDeError}},

)

# Instancias configuradas de la misma dependencia, con comportamiento distinto

filtro_completo = FiltroDeCatalogo(permitir_agotados=True)

filtro_disponibles = FiltroDeCatalogo(permitir_agotados=False)

@router.get(

 "",

 response_model=list[LibroRespuesta],

 summary="Listar el catálogo",

)

def listar_libros(

 libros: Annotated[list[dict], Depends(filtro_completo)],

 paginacion: PaginacionDep,

):

 return paginacion.aplicar(libros)

@router.get(

 "/disponibles",

 response_model=list[LibroRespuesta],

 summary="Listar solo los libros con ejemplares libres",

)

def listar_disponibles(

 libros: Annotated[list[dict], Depends(filtro_disponibles)],

 paginacion: PaginacionDep,

):

 return paginacion.aplicar(libros)

@router.get(

 "/{libro_id}",

 response_model=LibroRespuesta,

 summary="Consultar un libro",

)

def obtener_libro(libro: LibroExistente):

 # El 404 ya lo resolvió la dependencia; aquí solo queda devolver el recurso

 return libro

@router.post(

 "",

 response_model=LibroRespuesta,

 status_code=status.HTTP_201_CREATED,

 summary="Registrar un libro",

 responses={409: {"model": DetalleDeError}},

)

def crear_libro(datos: LibroCrear, bibliotecario: Bibliotecario):

 if crud_libros.existe_isbn(datos.isbn):

 raise ConflictoDeNegocio(

 f"Ya existe un libro registrado con el ISBN {datos.isbn}."

 )

 return crud_libros.crear(datos.model_dump())

@router.patch(

 "/{libro_id}",

 response_model=LibroRespuesta,

 summary="Actualizar parcialmente un libro",

)

def actualizar_libro(

 libro: LibroExistente,

 datos: LibroActualizar,

 bibliotecario: Bibliotecario,

):

 return crud_libros.actualizar(libro["id"], datos.model_dump(exclude_unset=True))

@router.delete(

 "/{libro_id}",

 status_code=status.HTTP_204_NO_CONTENT,

 summary="Eliminar un libro",

 responses={409: {"model": DetalleDeError}},

)

def eliminar_libro(libro: LibroExistente, bibliotecario: Bibliotecario):

 if crud_libros.tiene_prestamos_activos(libro["id"]):

 raise ConflictoDeNegocio(

 "No se puede eliminar un libro con ejemplares prestados."

 )

 crud_libros.eliminar(libro["id"])

 return Response(status_code=status.HTTP_204_NO_CONTENT)

app/routers/socios.py — dependencia a nivel de router

from fastapi import APIRouter, Depends

from app.dependencias import PaginacionDep, exigir_bibliotecario

from app.datos import SOCIOS

router = APIRouter(

 prefix="/socios",

 tags=["Socios"],

 # Se aplica a TODOS los endpoints del router. No se inyecta ningún valor:

 # solo se exige que la comprobación pase antes de ejecutar el endpoint.

 dependencies=[Depends(exigir_bibliotecario)],

)

@router.get("", summary="Listar socios")

def listar_socios(paginacion: PaginacionDep):

 return paginacion.aplicar(SOCIOS)

curl "http://127.0.0.1:8000/libros?categoria=novela&limite=1"

curl -i -X DELETE http://127.0.0.1:8000/libros/1

# 400 {"codigo":"error_de_dominio","mensaje":"Debe indicarse la cabecera X-Socio-Id."}

# Con un socio que no es bibliotecario (id 1) → tampoco pasa

# 400 {"mensaje":"Esta operación requiere el rol de bibliotecario."}

# Con el bibliotecario (id 2) → la operación se ejecuta

curl -i -X DELETE http://127.0.0.1:8000/libros/4 -H "X-Socio-Id: 2"

# HTTP/1.1 204 No Content

4. Ejemplo detallado: explicación línea por línea

N°

Elemento

Explicación

1

class Paginacion

Una clase como dependencia: FastAPI lee la firma de __init__, valida esos parámetros como query params y entrega la instancia ya construida.

2

Annotated[Paginacion, Depends()]

Depends() sin argumento reutiliza el tipo anotado como dependencia. Evita repetir Depends(Paginacion).

3

PaginacionDep = Annotated[...]

Alias reutilizable. Los endpoints escriben paginacion: PaginacionDep y la firma queda legible.

4

class FiltroDeCatalogo con __call__

__init__ recibe la configuración —fijada al crear la instancia— y __call__ recibe los query params de cada petición. Así una misma dependencia sirve con comportamientos distintos.

5

filtro_completo / filtro_disponibles

Dos instancias configuradas de la misma clase, usadas por dos endpoints distintos. Sin este patrón habría que duplicar la función de filtrado.

6

def obtener_libro_existente(libro_id: int)

El parámetro libro_id coincide con el de la ruta, así que FastAPI lo toma del path. La dependencia resuelve el 404 y el endpoint recibe el libro ya validado.

7

Header(alias="X-Socio-Id")

Las cabeceras HTTP usan guiones y los identificadores de Python no; alias hace la correspondencia explícita.

8

exigir_bibliotecario(socio: Depends(socio_actual))

Dependencia anidada: FastAPI resuelve primero socio_actual y le pasa el resultado. El grafo se construye solo.

9

raise dentro de la dependencia

Corta la petición antes de ejecutar el endpoint. El manejador registrado el 26 de agosto convierte la excepción en la respuesta adecuada.

10

dependencies=[Depends(...)] en APIRouter

Se ejecuta para todos los endpoints del router, pero no inyecta valor. Es la forma de exigir una condición sin ensuciar cada firma.

11

Orden de /disponibles y /{libro_id}

La ruta fija va primero. Si se declarara después, /libros/disponibles intentaría convertir «disponibles» a entero.

12

Caché por petición

socio_actual se invoca desde exigir_bibliotecario y podría invocarse desde otra dependencia: FastAPI la ejecuta una sola vez por petición.

5. Errores comunes y cómo evitarlos

Llamar a la dependencia en lugar de declararla: Depends(obtener_libro_existente()) la ejecuta al importar el módulo y produce «TypeError: missing 1 required positional argument: 'libro_id'».

Olvidar Depends y escribir paginacion: Paginacion: FastAPI intenta interpretar la clase como un modelo de cuerpo y responde 422 en todas las peticiones.

Usar dependencies=[...] esperando recibir el valor: esa forma solo ejecuta la dependencia; para obtener su resultado hay que declararla en la firma.

Poner la dependencia de rol solo en algunos endpoints del recurso y olvidar el resto. Si aplica a todos, va en el router.

Declarar /libros/{libro_id} antes que /libros/disponibles y recibir 422 en la ruta fija.

Meter lógica costosa en una dependencia sin recordar que se ejecuta en cada petición: una consulta pesada ahí se paga en todos los endpoints que la usan.
