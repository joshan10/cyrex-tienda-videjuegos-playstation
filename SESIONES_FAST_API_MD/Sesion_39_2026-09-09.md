Tema de la sesión

Consumo de APIs de IA externas desde FastAPI

1. Objetivo de la sesión

Al finalizar esta sesión, el aprendiz será capaz de consumir una API de IA generativa desde un endpoint propio: aislar la integración en una capa de servicio, autenticarse mediante una clave leída del entorno, usar un cliente HTTP asíncrono reutilizado, y sostener el servicio cuando el proveedor externo falla mediante tiempos límite, reintentos y degradación controlada.

2. Depender de un servicio que no controlamos

El modelo de ayer vive dentro del proceso: si el servidor está arriba, el modelo responde. Una API externa introduce una dependencia que puede tardar, fallar, cambiar de precio o dejar de existir. El diseño debe asumirlo desde el principio.

Riesgo

Cómo se contiene

Latencia alta

Tiempo límite explícito. Sin él, el cliente HTTP puede esperar indefinidamente y agotar las conexiones del servidor.

Fallo transitorio

Reintento con espera creciente, solo ante errores 5xx o de red. Nunca ante un 4xx: reintentar una petición mal formada la mantiene mal formada.

Límite de uso (429)

Respetar la cabecera Retry-After y degradar si se agota el margen.

Caída del proveedor

Degradación: una respuesta alternativa peor pero útil, en lugar de un error.

Coste por llamada

Caché de las respuestas repetidas y límite de longitud de la entrada.

Fuga de la clave

La clave vive en el entorno, nunca en el código ni en el repositorio, y jamás se devuelve al cliente.

Idea clave

La pregunta de diseño no es «¿qué respondo cuando el proveedor funciona?», sino «¿qué respondo cuando no funciona?». Si la respuesta es un 500, la disponibilidad de nuestra API pasa a ser la del proveedor. Una recomendación calculada con una consulta sencilla es peor que una generada por el modelo, y muchísimo mejor que un error.

El caso de BiblioAPI

Un socio describe en texto libre qué le apetece leer. El endpoint recupera el catálogo disponible, se lo entrega al modelo junto con la petición del socio, y devuelve tres recomendaciones justificadas. Si el proveedor no responde, se devuelven los libros disponibles de la categoría más prestada, marcando la respuesta como degradada.

Equivalencia con Django REST Framework

En DRF esta integración se resolvía con requests dentro de un método del serializer o de la vista, y el tiempo límite se olvidaba con frecuencia porque requests no lo impone. Aquí el cliente es httpx.AsyncClient, se crea una sola vez en el lifespan igual que el modelo de ayer, y la llamada se espera con await sin bloquear el servidor. El patrón de aislar la integración en una capa de servicio es idéntico en ambos frameworks y sigue siendo la parte más importante.

"""Integración con el proveedor de IA. Aísla el detalle del proveedor."""

import asyncio

import json

import logging

import httpx

from app.core.configuracion import configuracion

logger = logging.getLogger("biblioapi.ia")

INSTRUCCION = (

 "Eres el asistente de una biblioteca pública. A partir de los intereses "

 "del socio y del catálogo disponible, elige exactamente 3 libros. "

 "Responde ÚNICAMENTE con un arreglo JSON de objetos con las claves "

 "libro_id, titulo y motivo. El motivo debe tener máximo 25 palabras. "

 "No recomiendes libros que no estén en el catálogo."

)

class ProveedorNoDisponible(RuntimeError):

 """El proveedor externo no respondió de forma utilizable."""

class ServicioDeRecomendaciones:

 """Cliente del proveedor de IA. Se crea una vez y se reutiliza."""

 def __init__(self, cliente: httpx.AsyncClient):

 self._cliente = cliente

 self._clave = configuracion.proveedor_ia_api_key

 @property

 def configurado(self) -> bool:

 return self._clave is not None

 def _construir_mensaje(self, intereses: str, catalogo: list[dict]) -> str:

 return (

 f"Intereses del socio: {intereses}\n\n"

 f"Catálogo disponible:\n{json.dumps(catalogo, ensure_ascii=False)}"

 )

 async def recomendar(self, intereses: str, catalogo: list[dict]) -> list[dict]:

 """Llama al proveedor con reintentos. Lanza ProveedorNoDisponible si falla."""

 if not self.configurado:

 raise ProveedorNoDisponible("No hay clave de API configurada.")

 cuerpo = {

 "model": configuracion.proveedor_ia_modelo,

 "max_tokens": 700,

 "system": INSTRUCCION,

 "messages": [

 {"role": "user",

 "content": self._construir_mensaje(intereses, catalogo)}

 ],

 }

 cabeceras = {

 "x-api-key": self._clave,

 "anthropic-version": "2023-06-01",

 "content-type": "application/json",

 }

 for intento in range(configuracion.proveedor_ia_reintentos + 1):

 try:

 respuesta = await self._cliente.post(

 configuracion.proveedor_ia_url,

 json=cuerpo,

 headers=cabeceras,

 timeout=configuracion.proveedor_ia_timeout,

 )

 # 4xx: el problema es nuestro; reintentar no lo arregla

 if 400 <= respuesta.status_code < 500 and respuesta.status_code != 429:

 logger.error(

 "El proveedor rechazó la petición: %s %s",

 respuesta.status_code,

 respuesta.text[:200],

 )

 raise ProveedorNoDisponible(

 f"El proveedor respondió {respuesta.status_code}."

 )

 respuesta.raise_for_status()

 return self._extraer_recomendaciones(respuesta.json())

 except (httpx.TimeoutException, httpx.TransportError,

 httpx.HTTPStatusError) as exc:

 espera = 2**intento # espera creciente: 1 s, 2 s, 4 s

 logger.warning(

 "Intento %s fallido (%s). Reintentando en %s s.",

 intento + 1, type(exc).__name__, espera,

 )

 if intento == configuracion.proveedor_ia_reintentos:

 raise ProveedorNoDisponible(

 "El proveedor no respondió tras varios intentos."

 ) from exc

 await asyncio.sleep(espera)

 raise ProveedorNoDisponible("El proveedor no respondió.")

 @staticmethod

 def _extraer_recomendaciones(carga: dict) -> list[dict]:

 """Nunca se confía en la forma de la respuesta de un servicio externo."""

 try:

 texto = carga["content"][0]["text"].strip()

 except (KeyError, IndexError, TypeError) as exc:

 raise ProveedorNoDisponible("Respuesta del proveedor ilegible.") from exc

 # El modelo a veces envuelve el JSON en un bloque de código

 if texto.startswith("```"):

 texto = texto.split("```")[1]

 texto = texto.removeprefix("json").strip()

 try:

 datos = json.loads(texto)

 except json.JSONDecodeError as exc:

 raise ProveedorNoDisponible(

 "El proveedor no devolvió JSON válido."

 ) from exc

 if not isinstance(datos, list) or not datos:

 raise ProveedorNoDisponible("El proveedor devolvió una lista vacía.")

 return datos[:3]

import httpx

from app.services.recomendaciones import ServicioDeRecomendaciones

@asynccontextmanager

async def ciclo_de_vida(app: FastAPI):

 async with motor.begin() as conexion:

 await conexion.run_sync(Base.metadata.create_all)

 try:

 app.state.servicio_riesgo = ServicioDeRiesgo()

 except ModeloNoDisponible as exc:

 app.state.servicio_riesgo = None

 logger.warning("Modelo de riesgo no disponible: %s", exc)

 # Un único cliente reutilizado: mantiene vivas las conexiones

 limites = httpx.Limits(max_connections=20, max_keepalive_connections=10)

 app.state.cliente_http = httpx.AsyncClient(limits=limites)

 app.state.servicio_recomendaciones = ServicioDeRecomendaciones(

 app.state.cliente_http

 )

 if not app.state.servicio_recomendaciones.configurado:

 logger.warning("Sin clave de IA: las recomendaciones irán en modo degradado.")

 yield

 await app.state.cliente_http.aclose()

 await motor.dispose()

from typing import Annotated

from fastapi import APIRouter, Depends, Request

from sqlalchemy import func, select

from app.dependencias import SesionDep, SocioActual

from app.models.biblioteca import Categoria, Libro, Prestamo

from app.schemas.recomendacion import (

 LibroRecomendado,

 RespuestaDeRecomendacion,

 SolicitudDeRecomendacion,

)

from app.services.recomendaciones import (

 ProveedorNoDisponible,

 ServicioDeRecomendaciones,

)

router = APIRouter(prefix="/recomendaciones", tags=["Recomendaciones"])

def obtener_servicio(peticion: Request) -> ServicioDeRecomendaciones:

 return peticion.app.state.servicio_recomendaciones

ServicioIA = Annotated[ServicioDeRecomendaciones, Depends(obtener_servicio)]

async def _catalogo_disponible(sesion) -> list[dict]:

 """Solo lo imprescindible: cuanto más corto el mensaje, menor el coste."""

 consulta = (

 select(Libro).where(Libro.ejemplares_disponibles > 0).limit(40)

 )

 resultado = await sesion.scalars(consulta)

 return [

 {

 "libro_id": libro.id,

 "titulo": libro.titulo,

 "autor": libro.autor.nombre,

 "categoria": libro.categoria.nombre,

 }

 for libro in resultado.unique()

 ]

async def _respaldo_local(sesion) -> list[LibroRecomendado]:

 """Degradación: la categoría más prestada, con libros disponibles."""

 categoria_id = await sesion.scalar(

 select(Libro.categoria_id)

 .join(Prestamo, Prestamo.libro_id == Libro.id)

 .group_by(Libro.categoria_id)

 .order_by(func.count().desc())

 .limit(1)

 )

 consulta = select(Libro).where(Libro.ejemplares_disponibles > 0)

 if categoria_id is not None:

 consulta = consulta.where(Libro.categoria_id == categoria_id)

 resultado = await sesion.scalars(consulta.limit(3))

 return [

 LibroRecomendado(

 libro_id=libro.id,

 titulo=libro.titulo,

 motivo=f"Disponible ahora en la categoría {libro.categoria.nombre}.",

 )

 for libro in resultado.unique()

 ]

@router.post(

 "",

 response_model=RespuestaDeRecomendacion,

 summary="Recomendar tres libros a partir de los intereses del socio",

)

async def recomendar(

 sesion: SesionDep,

 datos: SolicitudDeRecomendacion,

 servicio: ServicioIA,

 socio: SocioActual,

):

 catalogo = await _catalogo_disponible(sesion)

 titulos_validos = {libro["libro_id"] for libro in catalogo}

 try:

 crudas = await servicio.recomendar(datos.intereses, catalogo)

 except ProveedorNoDisponible:

 return RespuestaDeRecomendacion(

 recomendaciones=await _respaldo_local(sesion),

 generada_por="catalogo_local",

 aviso=(

 "El asistente no está disponible en este momento; "

 "estas sugerencias vienen del catálogo."

 ),

 )

 # El modelo puede inventar libros: se descarta lo que no está en el catálogo

 validas = [

 LibroRecomendado(**item)

 for item in crudas

 if item.get("libro_id") in titulos_validos

 ]

 if not validas:

 return RespuestaDeRecomendacion(

 recomendaciones=await _respaldo_local(sesion),

 generada_por="catalogo_local",

 aviso="El asistente sugirió libros que no están en el catálogo.",

 )

 return RespuestaDeRecomendacion(

 recomendaciones=validas,

 generada_por="modelo_externo",

 )

4. Ejemplo detallado: explicación línea por línea

N°

Elemento

Explicación

1

proveedor_ia_api_key: str | None = None

La clave puede faltar y la aplicación arranca igual: el endpoint funciona en modo degradado en lugar de impedir el despliegue.

2

httpx.AsyncClient creado en el lifespan

Un cliente por aplicación, no por petición. Reutiliza las conexiones TCP y evita rehacer la negociación TLS en cada llamada.

3

httpx.Limits(max_connections=20)

Techo de conexiones simultáneas hacia el proveedor. Sin límite, un pico de tráfico puede agotar los descriptores del servidor.

4

timeout=configuracion.proveedor_ia_timeout

Tiempo límite explícito. httpx trae uno por defecto de 5 s, pero fijarlo deja la decisión escrita y ajustable por entorno.

5

4xx distinto de 429 → no se reintenta

Un 401 por clave inválida o un 400 por cuerpo mal formado se repetirán idénticos. Reintentar solo gasta tiempo y dinero.

6

espera = 2**intento

Espera creciente: 1 s, 2 s, 4 s. Reintentar de inmediato agrava la saturación del servicio que ya está sufriendo.

7

raise … from exc

Conserva la excepción original en la traza. Al depurar se ve si fue un timeout o un error de conexión.

8

_extraer_recomendaciones

La respuesta externa se valida antes de usarse. Un KeyError sin controlar convertiría un cambio en el formato del proveedor en un 500 de nuestra API.

9

Limpieza del bloque ```json

Los modelos de lenguaje suelen envolver el JSON en un bloque de código aunque se les pida lo contrario. Se contempla en el código, no en la esperanza.

10

titulos_validos y filtrado

Un modelo puede inventar un libro que no existe. Solo se devuelven identificadores presentes en el catálogo que se le envió.

11

_respaldo_local

La degradación es una consulta a la base: peor recomendación, servicio disponible. El cliente recibe 200 y sabe por generada_por de dónde salió.

12

generada_por y aviso

Transparencia: el consumidor distingue una recomendación del modelo de una del catálogo, y puede mostrarlo en la interfaz.

13

min_length en intereses

Corta las entradas inútiles antes de gastar una llamada de pago. La validación barata va primero.

14

limit(40) en el catálogo

Acota el tamaño del mensaje. El coste de estas APIs es proporcional al texto enviado.

15

await cliente_http.aclose()

Cierra el cliente al apagar la aplicación y libera las conexiones abiertas.

5. Errores comunes y cómo evitarlos

Escribir la clave de API en el código o subirla al repositorio. Una clave publicada en GitHub se detecta y se explota en minutos; si ocurre, se revoca de inmediato.

Crear un httpx.AsyncClient dentro del endpoint: se rehace la conexión en cada petición y las conexiones quedan sin cerrar.

Llamar sin tiempo límite: una petición colgada retiene una conexión indefinidamente y, con suficiente tráfico, tumba el servidor.

Reintentar ante cualquier error, incluidos los 4xx: se multiplica el gasto sin ninguna posibilidad de éxito.

Reintentar sin espera creciente: se castiga a un servicio que ya está degradado y es habitual que responda con un bloqueo temporal.

Confiar en la forma de la respuesta externa: acceder a carga["content"][0]["text"] sin control convierte cualquier cambio del proveedor en un 500 propio.

Devolver al cliente lo que dijo el modelo sin validarlo: se acaban recomendando libros que la biblioteca no tiene.

Usar requests dentro de un async def: es una librería síncrona y bloquea el bucle de eventos aunque la función esté declarada como asíncrona.

Propagar el error del proveedor como un 500 propio: la disponibilidad de nuestra API pasa a depender por completo de un tercero.
