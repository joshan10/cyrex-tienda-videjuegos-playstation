2. Mapa de conceptos repasados

Sesión

Tema

Lo que debe quedar claro

37

Bases de datos asíncronas

async cede el control en cada await y mejora la concurrencia, no la latencia de una petición. Las operaciones de CPU bloquean el bucle. En async no puede quedar carga perezosa sobre atributos que se van a leer.

38

Modelos de IA propios

El modelo se entrena fuera, se serializa con su preprocesamiento y se carga una vez en el lifespan. La inferencia sale del bucle con run_in_threadpool. El modelo estima, no decide.

39

APIs de IA externas

Toda llamada externa lleva tiempo límite; se reintenta solo ante 5xx o error de red, con espera creciente; se valida la respuesta; y se degrada con una alternativa útil cuando el proveedor falla.

Idea clave

Las tres sesiones tratan la misma pregunta desde ángulos distintos: qué hacer mientras se espera algo que no depende de nosotros. Con la base de datos, ceder el control; con el modelo local, salir del bucle; con el proveedor externo, poner un límite y tener un plan B.

Pregunta

Respuesta esperada

1

¿async hace más rápida una consulta a la base?

No. La consulta tarda lo mismo. Lo que mejora es cuántas peticiones concurrentes soporta el servidor.

2

Aparece MissingGreenlet al serializar la respuesta. ¿Qué ocurrió?

Se leyó una relación perezosa fuera de un await. Se resuelve con carga eager o cargándola en la consulta.

3

¿Por qué expire_on_commit=False es obligatorio en async?

Porque con los objetos caducados, leer cualquier atributo después del commit dispararía E/S implícita, imposible fuera de un await.

4

¿Dónde se carga el modelo de scikit-learn y por qué ahí?

En el lifespan, una sola vez. Cargarlo por petición añade cientos de milisegundos a cada llamada.

5

¿Qué pasa si la inferencia se ejecuta directamente en un async def?

Bloquea el bucle de eventos: todas las peticiones en curso se detienen, no solo esa.

6

¿Por qué se serializa el pipeline y no solo el clasificador?

Para que el preprocesamiento sea exactamente el mismo en entrenamiento y en producción. Reproducirlo a mano introduce diferencias silenciosas.

7

El proveedor externo responde 401. ¿Se reintenta?

No. Un 4xx indica un problema en nuestra petición y se repetirá igual. Solo se reintenta ante 5xx, 429 o errores de red.

8

¿Por qué se filtra lo que devuelve el modelo de lenguaje?

Porque puede inventar elementos que no existen en nuestros datos. Solo se aceptan identificadores presentes en el catálogo enviado.

9

¿Qué se responde cuando el proveedor externo está caído?

Una alternativa calculada localmente, con 200 y un campo que indica que la respuesta es degradada. Nunca un 500.

3. Ejemplo integrador guiado

Enunciado: construir GET /sistema/diagnostico, un endpoint que comprueba en paralelo la base de datos, el modelo local de riesgo y el proveedor externo de IA, con un tiempo límite propio para cada comprobación, y devuelve el estado y la latencia de cada uno. Nunca falla: si una comprobación se cae, lo reporta.

app/schemas/diagnostico.py — nuevo archivo

from typing import Literal

from pydantic import BaseModel

class EstadoComponente(BaseModel):

 componente: str

 estado: Literal["ok", "degradado", "caido"]

 latencia_ms: float | None = None

 detalle: str | None = None

class Diagnostico(BaseModel):

 estado_general: Literal["ok", "degradado", "caido"]

 componentes: list[EstadoComponente]

app/routers/sistema.py — nuevo archivo

import asyncio

import time

from fastapi import APIRouter, Request

from fastapi.concurrency import run_in_threadpool

from sqlalchemy import select

from app.dependencias import Bibliotecario, SesionDep

from app.models.biblioteca import Libro

from app.schemas.diagnostico import Diagnostico, EstadoComponente

router = APIRouter(prefix="/sistema", tags=["Sistema"])

LIMITE_POR_COMPROBACION = 5.0

async def _medir(nombre: str, corrutina) -> EstadoComponente:

 """Ejecuta una comprobación con tiempo límite y mide cuánto tardó."""

 inicio = time.perf_counter()

 try:

 detalle = await asyncio.wait_for(corrutina, timeout=LIMITE_POR_COMPROBACION)

 estado = "ok"

 except asyncio.TimeoutError:

 detalle, estado = "No respondió dentro del límite.", "caido"

 except Exception as exc: # noqa: BLE001 — el diagnóstico nunca debe fallar

 detalle, estado = f"{type(exc).__name__}: {exc}", "caido"

 return EstadoComponente(

 componente=nombre,

 estado=estado,

 latencia_ms=round((time.perf_counter() - inicio) * 1000, 1),

 detalle=detalle,

 )

async def _comprobar_base(sesion) -> str:

 total = await sesion.scalar(select(Libro.id).limit(1))

 return f"Consulta ejecutada (hay datos: {total is not None})."

async def _comprobar_modelo(servicio) -> str:

 if servicio is None:

 raise RuntimeError("El modelo no está cargado.")

 variables = {

 "dias_prestamo": 15,

 "prestamos_previos": 5,

 "retrasos_previos": 1,

 "ejemplares_disponibles": 3,

 "categoria": "novela",

 }

 # Inferencia de prueba, fuera del bucle de eventos

 probabilidad = await run_in_threadpool(servicio.predecir, variables)

 return f"Predicción de prueba: {probabilidad:.3f} ({servicio.version})."

async def _comprobar_proveedor(servicio) -> str:

 if not servicio.configurado:

 raise RuntimeError("Sin clave de API configurada.")

 await servicio.recomendar(

 "prueba de diagnóstico",

 [{"libro_id": 1, "titulo": "Prueba", "autor": "—", "categoria": "novela"}],

 )

 return "El proveedor respondió correctamente."

@router.get(

 "/diagnostico",

 response_model=Diagnostico,

 summary="Estado de la base de datos y de las integraciones de IA",

)

async def diagnostico(

 peticion: Request,

 sesion: SesionDep,

 bibliotecario: Bibliotecario,

):

 estado = peticion.app.state

 # Las tres comprobaciones se lanzan a la vez: el endpoint tarda

 # lo que tarde la más lenta, no la suma de las tres.

 componentes = await asyncio.gather(

 _medir("base_de_datos", _comprobar_base(sesion)),

 _medir("modelo_riesgo", _comprobar_modelo(getattr(estado, "servicio_riesgo", None))),

 _medir("proveedor_ia", _comprobar_proveedor(estado.servicio_recomendaciones)),

 )

 # La base caída es crítica; las integraciones de IA solo degradan

 base = componentes[0]

 if base.estado == "caido":

 general = "caido"

 elif any(c.estado != "ok" for c in componentes):

 general = "degradado"

 else:

 general = "ok"

 return Diagnostico(estado_general=general, componentes=list(componentes))

4. Errores comunes recopilados de las sesiones anteriores

Olvidar un await y devolver una corrutina: el error aparece al serializar la respuesta y despista, porque señala al esquema y no a la línea que falta.

Recorrer una relación perezosa en async: MissingGreenlet. Se declara eager lo que se va a leer.

Ejecutar la inferencia del modelo directamente en un async def y bloquear el bucle de eventos.

Cargar el modelo o crear el cliente HTTP dentro del endpoint en lugar del lifespan.

Llamar a un servicio externo sin tiempo límite, o esperar las comprobaciones una tras otra en lugar de lanzarlas con asyncio.gather.

Reintentar ante un 4xx del proveedor y multiplicar el gasto sin ninguna posibilidad de éxito.

Dejar que un fallo de una integración accesoria devuelva 500 y tumbe funciones que no dependían de ella.

Dejar el endpoint de diagnóstico abierto sin autenticación: revela qué integraciones existen y cuáles están caídas.
